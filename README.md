# CodeSphere – Coding Blog

A modern, production‑ready coding blog built with React, Vite, Tailwind CSS, Cloudflare Workers, and D1.

## Features
- 🔐 Authentication with HttpOnly cookies (no tokens in localStorage)
- 👑 Admin/User roles
- 📝 Full CRUD for blog posts
- 🌗 Dark/Light theme (persisted in localStorage)
- 📱 Responsive design
- ⚡ Server‑side validation and prepared statements
- 📊 Admin dashboard with stats and user management

## Technology Stack
- **Frontend:** React 18, React Router DOM, Tailwind CSS, Vite
- **Backend:** Cloudflare Workers, D1 (SQLite)
- **Deployment:** Wrangler

## Prerequisites
- Node.js 16+
- Cloudflare account
- Wrangler CLI (`npm install -g wrangler`)
